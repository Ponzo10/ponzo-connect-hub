# PONZO Connect

Crée une application de réseau social professionnelle appelée PONZO. Utilise l'image que j'ai jointe comme source d'inspiration pour le design et l'expérience utilisateur, mais ne la copie pas exactement. Je veux une interface moderne, élégante, rapide et fluide, inspirée de Facebook, TikTok et Instagram, tout en gardant l'identité unique de PONZO. Les couleurs principales sont le vert, le jaune et le blanc. L'application doit être responsive et fonctionner parfaitement sur Android, iPhone et le Web.
